# Hisn-Web-Design

Design workspace for the Hisn (حصن) website, Phase 2: discovery, direction and prototypes, before anything goes into the app repo.

| Path | What it is |
|---|---|
| `design/01-discovery.md` | Discovery and two visual directions (start here) |
| `hisn-redesign-prompt.md` | The design brief |
| `dev-1.md` | Frontend task list (D1-1 to D1-17) |
| `دليل الهوية البصرية - لجنة الدعم الفني.pdf` | Brand guide, part 1 (Arabic, 20 pages) |
| `دليل الهوية البصرية - لجنة الدعم الفني.zip` | Brand kit, batch 1 (logos, colors, tokens) |
| `Screenshot 2026-11-14 at 4.07.17 PM.png` | Committee content request |

The brand kit's extracted copy (`brand-kit/`) is git-ignored. Recreate it with:

```bash
unzip "دليل الهوية البصرية - لجنة الدعم الفني.zip" -d brand-kit
```
